Getting started

Installation

Install the repository into an isolated Python environment; these commands do not depend on a PyPI release:

git clone https://github.com/unixwzrd/code-analytics.git
cd code-analytics
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install .
code-analysis doctor

Choose optional capabilities explicitly from the checkout:

python -m pip install '.[javascript]'  # JavaScript/JSX parsing
python -m pip install '.[tui]'         # terminal investigation
python -m pip install '.[runtime]'     # explicit coverage/profiling workflows

The base installation supports Python analysis and saved-report browsing without Node, Ruby or optional language parsers. JavaScript uses pinned Tree-sitter bindings and grammar, not Node or npm. Ruby analysis uses an existing configured Ruby/Prism installation through an external parser driver; it does not load the target Ruby application. Run doctor and providers to check availability. Missing parsers remain visible as unavailable evidence.

The separate semantic extra requires an explicitly configured existing local model; the tool never downloads a model automatically. See the CLI reference for optional-provider configuration.

On macOS, code-analysis opens or reuses a compatible background UI session and returns your prompt. Closing the browser tab leaves that session running; use Stop Code Analysis or code-analysis ui-stop to stop it. For terminal-controlled operation without browser launch, use code-analysis ui --foreground --no-open. In Browse code, use Connect source folder if needed, then select a graph node to display its source directly. Nearby README files and their local text links open in a separate read-only project reader. Global Help opens the bundled offline guide. See the UI guide for collection roots, source binding and browser preferences.

Everyday commands

code-analysis doctor
code-analysis providers
code-analysis scan .
code-analysis refactor . --json-compact -o refactor.json
code-analysis summary refactor.json
code-analysis diff baseline.json candidate.json --format markdown
code-analysis export refactor.json --projection dependencies --format svg -o dependencies.svg
code-analysis ui refactor.json --source-root . --no-collection

The CLI reference, examples, UI guide and report and diagram catalog cover focused analysis, queries, projections, comparisons, workspaces and explicit runtime evidence. SVG rendering requires the optional Graphviz executable; a missing renderer is an error, not an empty diagram.
