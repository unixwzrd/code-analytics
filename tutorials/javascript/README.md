# Fawlty Towers investigations — Javascript

Sybil has hired you to explain a working hotel reservation system before the next policy change. Each level is an independent episode with its own incident report, mission, runnable application and evaluation material.

- [Beginner — The Reservation Desk](beginner/README.md): follow Ada's arrival-to-receipt experience.
- [Intermediate — The Booking Mix-Up](intermediate/README.md): investigate the standard-room and annex booking scenarios.
- [Advanced — The Hotel From Hell](advanced/README.md): investigate group requests, cancellation and repeated submissions.

Each level's README contains the exact launch/test commands and the saved-report command with its explicit source root. Source is in `src/` and behavior checks are in `tests/`. Work through the independent investigation, consult optional HINTS.md only if needed, record your findings checklist and then open SOLUTIONS.md. Do not read the expected-evidence manifest or qualification note before your investigation if you want to avoid spoilers.

Common setup, the integer-penny baseline, temporary persistence and evidence-handling notes are in the [tutorial guide](../README.md). Use the [shared workflow](../UI-WALKTHROUGH.md) for help with navigation and the distinction between an observation and a conclusion. The basic assignment is static and requires no runtime collection.

Runtime profiling is not part of this language's tutorial assignment or qualification. Use only the capabilities documented in the supplied static report and the later solutions; do not infer feature parity from another language's results.
